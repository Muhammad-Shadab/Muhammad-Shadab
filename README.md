### About Me

I'm a Mobile Engineer with experience shipping production Android and Flutter applications since 2021, currently working as an **SDE II at NovoStack**. My work spans native Android (Kotlin/Java), Flutter/Dart, mobile architecture, API and SDK integration, and release automation — primarily across FinTech, lending, and payments products.

- Mobile architecture — **MVVM**, Clean Architecture, modular codebases
- API integration, authentication, and third-party SDK integration
- Android SDK and Flutter package development for internal and public use
- CI/CD, release automation, and app store publishing (Play Store & App Store)
- FinTech, lending, and payment-integration domain experience
