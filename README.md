### About Me

I'm a Senior Android & Flutter engineer with 4.5+ years building production fintech apps in Kotlin, Java and Dart, currently a **Senior Mobile Developer (SDE II) at Novostack**, Noida. I work with Jetpack Compose, Coroutines, Hilt, MVVM and Clean Architecture on Android, Flutter with BLoC and GetX, and reusable SDKs for lending, payments and KYC journeys.

- Mobile architecture — **MVVM**, Clean Architecture, Repository pattern, multi-module apps, offline-first
- Reusable SDKs — eligibility (BRE), multi-lender loan journeys, shared networking
- Mobile security — SSL pinning, Keystore, encrypted storage, Play Integrity, root/jailbreak detection, VAPT fixes
- Fintech integrations — UPI, Razorpay, PayU, Juspay, Cashfree, CIBIL/CRIF, Digio eKYC, NSDL
- Releases — Play Store & App Store with Fastlane, GitHub Actions, TestFlight and Shorebird
